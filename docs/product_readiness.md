# ViralPick AI 产品化就绪清单

本文档用于判断项目距离“可推出的正式商业产品”还差哪些工程与产品能力。

## 当前已具备

- 完整数据链路：国内电商经营数据生成、数据质量校验、CSV 输出、SQLite 初始化。
- 后端 API：商品、销售、爆品评分、评论洞察、竞品对比、预测和报告。
- 前端工作台：多页面导航、商品货架雷达、跨页商品切换、竞品详情对比、图表、筛选、报告生成、移动端适配。
- 生产运行入口：`wsgi.py`、Gunicorn、Dockerfile、Docker Compose。
- 基础账号体系：默认管理员、登录、退出、Bearer token、当前用户接口、失败登录临时锁定。
- 基础团队治理：邀请链接入驻、成员列表、兼容直接创建成员、角色调整、账号启停和审计日志。
- 集中式权限矩阵：后端统一 `require_permission()` 守卫，前端按权限控制报告、导入、评分模型、团队、审计和运维操作入口。
- 审计中心：关键操作查询、动作筛选、资源筛选、成员筛选和摘要统计。
- 租户基础表：`workspaces`、`users`、`api_tokens`、`audit_logs`。
- SQLite schema 迁移记录：`schema_migrations`、迁移脚本和 `/api/ready` pending migration 检查。
- 数据导入基础能力：登录后 CSV 模板下载、上传、字段校验、错误报告下载、导入任务记录和部分业务表受控替换。
- AI 报告增强：Spark X HTTP 适配层、脱敏状态接口、规则模板回退。
- 爆品评分模型治理：具备 `scoring.manage` 权限的用户可配置权重、创建激活版本并保留模型历史。
- 定时运营报告：具备 `reports.schedule` 权限的用户可创建周期报告任务、配置邮件收件人、暂停/启用、手动执行、执行到期任务、追踪最近报告和交付结果，并对失败或跳过的交付记录发起手动重试；可恢复失败会进入自动重试队列。
- 报告交付：Word、PDF、HTML、Markdown 文件导出，带有效期、可撤销的只读分享链接、脱敏访客访问明细，自动交付重试队列，以及独立的品牌化公开报告阅读模式。
- 工作区品牌模板：具备品牌名称、报告副标题、Logo URL、主色、强调色和公开报告封面风格配置。
- 运维中心：具备运维权限的用户可查看应用状态、规则化监控告警、Webhook 告警通道、数据库表规模、备份列表和后台自动化运行记录，手动发送告警，手动创建/校验 SQLite 备份，并通过 CLI 执行到期报告、交付重试和受控恢复。
- 健康检查：`/api/health` 和 `/api/ready`。
- 基础安全响应头：`X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy`、`Permissions-Policy`。
- 基础请求防护：上传大小限制、生产默认启用的进程内 API 限流、登录失败锁定和 429 响应头。
- 请求追踪：`X-Request-ID` 和请求日志。
- 自动化验证：pytest、前端 JS 语法检查、HTTP smoke test、GitHub Actions CI。
- 数据合规声明：明确区分公开数据集字段结构参考、经营分析数据和市场对照指标。

## 正式商用前必须补齐

### 账号与权限

- 用户注册、密码重置、邮箱验证和真实邮件发送。
- MFA、会话设备管理、异常登录提醒和地理/设备风险识别。
- 更完整的密码策略、密码轮换、历史密码限制和分布式登录风控。
- 更细粒度的资源实例权限，例如按单个数据源、报告、店铺或工作空间子资源授权。
- 审计日志导出、长期归档和异常操作告警。

### 数据接入

- 批量导入失败重试、导入模板版本管理和错误报告归档。
- 合法授权平台 API 接入。
- 数据源配置、同步记录和数据血缘。
- 核心指标重算流水线，支持替换产品主表后自动重建派生指标。

### 多租户与数据库

- 从 SQLite 迁移到 PostgreSQL 或 MySQL。
- 租户隔离、表级索引优化、成熟迁移工具和回滚策略。
- 自动备份调度、远端对象存储、备份加密和数据保留策略。

### 报告与智能化

- 分享链接的访问者身份校验、细粒度权限控制和访问异常提醒。
- 多品牌模板库、客户级模板审批、批量报告、真实后台调度器、退信处理和邮件/消息投递监控。
- 评分模型效果回测、审批流和按品类/店铺自动切换策略。
- 提示词版本管理、大模型输出审核、敏感词与事实一致性校验。

### 运维与安全

- 生产反向代理和 HTTPS。
- Secret 管理。
- 网关级或 Redis 级分布式速率限制。
- 外部 APM、性能监控、生产级分布式任务队列、自动告警调度、告警重试队列和告警处理流转。
- 依赖漏洞扫描。

### 质量保障

- 前端 E2E 测试。
- API 契约测试。
- 大数据量性能测试。
- 真实部署环境 smoke test。
- 浏览器兼容性测试。

## 推荐里程碑

1. **MVP 展示版**：当前版本，适合课程答辩、作品集演示和本地产品原型展示。
2. **内测版**：补真实邮件发送运维规范、导入失败重试、数据库迁移、多模板品牌库和细粒度权限。
3. **商业试点版**：补真实授权 API、审计日志导出与归档、外部 APM、自动告警调度和部署流水线。
4. **正式商业版**：补 SLA、数据安全合规、计费、客户支持和生产运维流程。

## 当前结论

当前项目已经从课程 demo 推进到“产品化原型”阶段，并具备基础认证、团队成员管理、集中式权限矩阵、审计中心、CSV 模板与错误报告、AI 报告增强、评分模型配置、报告导出、定时运营报告任务、邮件交付记录、手动交付重试、自动交付重试队列、轻量后台自动化 worker、工作区品牌模板、品牌化公开报告分享、脱敏分享访问审计、SQLite schema 迁移记录、规则化监控告警、Webhook 告警通知、基础运维备份、备份校验、受控恢复脚本和部署能力，但还不能声称是可直接面向真实商家公网售卖的正式 SaaS。继续推进时应优先补真实授权 API、生产数据库迁移到 PostgreSQL/MySQL、资源实例级授权、生产级分布式任务队列、退信处理、外部投递监控、自动备份调度、远端对象存储、外部 APM、自动告警调度和多品牌模板审批。
