# ViralPick AI 导入示例文件

这些 CSV 文件用于验证“数据接入中心”的上传、字段识别、质量检查和确认导入流程。

建议导入顺序：

1. `products.csv`
2. `sales_daily.csv`
3. `orders_daily.csv`
4. `comments.csv`
5. `inventory_daily.csv`
6. `after_sales.csv`
7. `ad_metrics.csv`
8. `traffic_metrics.csv`
9. `content_metrics.csv`

文件列名刻意使用商家常见中文字段，系统会自动映射到标准字段。
